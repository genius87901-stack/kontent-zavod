# Свой банк музыки — пошагово

Этот текст — для вас, не для чтения агентом вслух. Скажите помощнику
**«хочу подключить свою музыку»** в любой момент — он проведёт по этим же
шагам своими словами и сам выполнит техническую часть.

## Зачем это вам

Reels без вашего голоса (демонстрация, сравнение «до/после») собираются под
музыку. Раньше эта музыка была общей у всех клиентов завода — теперь у вас
будет **своя**, которую выбрали лично вы, и никто другой её не использует.

## Шаг 1. Регистрация — без ключей и API

Никакого технического ключа заводить не нужно — это не то место, где он
бывает. Просто обычная регистрация на сайте:

1. Откройте **pixabay.com/music** в браузере.
2. Нажмите «Войти» / «Sign up» — заведите бесплатный аккаунт (почта или
   Google-вход).
3. Всё, регистрация закончена — дальше только поиск и кнопка «Скачать».

## Шаг 2. Найдите треки, которые вам нравятся

В строке поиска — слово по настроению: `corporate`, `lofi`, `chill`,
`upbeat`, `cinematic` и подобные. Один трек проще подобрать, чем словосочетание —
если ничего не находится, попробуйте другое одно слово.

Слушайте прямо на сайте (кнопка Play рядом с треком). Хороший фоновый трек —
без вокала, ровный по энергии, длиной от 30 секунд.

## Шаг 3. Скачайте — сколько хотите

Кнопка **Download** рядом с треком → выбрать mp3. Лимита на количество нет —
это бесплатный тариф Pixabay, качайте сколько нужно. Файл ляжет в обычную
папку загрузок вашего компьютера (`Downloads` / «Загрузки»).

**Имя файла не переименовывайте** — по нему потом видно, откуда трек.

## Шаг 4. Отдайте файлы заводу

Скажите помощнику: **«я скачал музыку, вот она»** — и укажите папку (обычно
это и есть `Downloads`/«Загрузки»). Помощник сам разложит файлы в нужное
место командой:

```
python install/install_music.py --src "путь к папке с вашими mp3"
```

Ничего не перезапишется и не задвоится — команду можно повторять сколько
угодно, добавятся только новые файлы. Проверить, что уже лежит в банке:
**«покажи, что с музыкой»** → `python install/install_music.py --status`.

## Что дальше

С этого момента Reels без вашего голоса сами берут музыку из вашего банка —
ничего больше делать не нужно, каждый следующий такой ролик просто её
использует.

## Если пока не хочется собирать свой банк

Ничего страшного — завод и без него соберёт нужный ролик. Просто в вашей
музыке он будет звучать только после того, как вы пройдёте шаги выше.
