# Как выгрузить все переписки из Telegram (RU)

Нужен **Telegram Desktop** — мобильное приложение полный экспорт НЕ умеет.

1. Установите Telegram Desktop с официальной страницы: **https://desktop.telegram.org**
   (Windows / macOS / Linux). Войдите в свой аккаунт.
2. Меню → **Settings (Настройки)** → **Advanced (Продвинутые настройки)**.
3. Пролистайте вниз до **Export Telegram data (Экспорт данных Telegram)** —
   нажмите.
4. В окне экспорта, раздел **What to include (Что включить)**:
   - оставьте включённым **Personal chats (Личные чаты)**;
   - СНИМИТЕ галочки с медиа: Photos, Video, Voice messages, Video messages,
     Stickers, GIFs, Files — они не нужны для сегментации и сильно раздувают
     выгрузку. Оставьте только текст.
   - (по желанию) можно включить **Contacts list (Список контактов)** — тогда
     подтянутся телефоны.
5. Раздел **Location and format (Расположение и формат)**:
   - **Format = HTML** (это важно — не JSON);
   - выберите папку, куда сохранить.
6. Нажмите **Export (Экспортировать)** и дождитесь завершения (может занять
   несколько минут — часов, зависит от объёма). Telegram может попросить
   подождать 24 часа в целях безопасности — это нормально, дождитесь.
7. В указанной папке появится папка выгрузки (внутри есть подпапки **lists/**
   и **chats/**). Пришлите Claude полный путь к этой папке.

## (Опционально) Получить api_id / api_hash — для @username и группы «Б»

Нужны, только если хотите колонку «Аккаунт» и поиск забытых контактов по bio.

1. Откройте **https://my.telegram.org** → введите номер → код придёт
   **в сам Telegram** (не по SMS), введите его.
2. Раздел **API development tools**.
   - Если поля **App api_id** и **App api_hash** уже видны — приложение уже
     создано, просто скопируйте их.
   - Если нужно создать: **App title** = `parser`, **Short name** = `parser01`
     (5–32 симв., только латиница, без пробелов), **Platform** = Desktop,
     URL оставьте пустым → **Create application**.
3. Частый баг: форма пишет **ERROR**, хотя приложение уже создалось — просто
   **обновите страницу** и снова зайдите в раздел, ключи будут там. Если нет —
   переключите язык на English, попробуйте Chrome-инкогнито без расширений,
   при необходимости с VPN / без VPN или с мобильного интернета.
4. Скопируйте `api_id` (число) и `api_hash` (строка) — их спросит tg_profiles.py.
