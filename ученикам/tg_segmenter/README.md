# TG Segmenter

Автономная функция для Claude: превращает выгрузку личных переписок Telegram в
приоритизированную Excel-таблицу контактов с персональными сообщениями для
возобновления диалога. Рубрика сегментации строится под ваш бизнес по ответам
на 5 вопросов.

## Запуск
1. Ничего запускать не нужно — функция приехала обновлением завода.
2. Скажите Claude: **«прочитай ученикам/tg_segmenter/AGENT.md и начни работу»**.
3. Дальше Claude всё ведёт сам: интервью → инструкция по выгрузке → парсинг →
   сегментация → Excel.

Работает по подписке (без ANTHROPIC_API_KEY). Требует python3 + openpyxl.
Данные не покидают вашу машину. Отправку сообщений делаете вы вручную.

## Состав
- `AGENT.md` — инструкция-функция для Claude (точка входа).
- `HOWTO_EXPORT_RU.md` / `HOWTO_EXPORT_EN.md` — как выгрузить Telegram.
- `parse_telegram.py` — парсер HTML-выгрузки → CSV.
- `prefilter.py` — дешёвая фильтрация без модели.
- `score_batch.py` — запись размеченного батча + подсчёт балла (с валидацией).
- `build_xlsx.py` — сборка рабочей Excel-таблицы.
- `tg_profiles.py` — (опц., Telethon) сбор @username + bio по всем контактам.
- `enrich_usernames.py` — приклеивает @username к базе (колонка «Аккаунт»).
- `build_groupB.py` — группа «Б»: забытые контакты по bio под вашу ЦА.

Расширение с @username и группой «Б» требует своих api_id/api_hash с
my.telegram.org (первый вход клиент делает сам) и `pip install telethon`.
