# РАСПАКОВКА — 〔Имя клиента〕 | 〔Ниша одной фразой〕

_Заполняется НА живой сессии (ведёт Валерия, пишет агент/Валерия). Всё в 〔…〕 —
заменить словами клиента. Дословные фразы клиента брать в «кавычки» и помечать
[дословно] — они самые ценные. Пустое поле = пустой контент, не формальность._

_Готовый файл раскладывается в персональный Content Bible клиента (каркас —
`ученикам/04_CONTENT_BIBLE_ШАБЛОН.md`) и в БЛОК СМЫСЛОВ промта
`ПРОМТ_КОНТЕНТ.md`. Разметка полей ниже совпадает с ними 1:1._

## ЧЕК-ЛИСТ ЗАКРЫТИЯ СЕССИИ

- [ ] Позиционирование заполнено, есть «против течения» и «кому не подхожу»
- [ ] 5–7 болей — все в кавычках и дословно, ни одна не проходит как «про любого»
- [ ] Есть якорная история в структуре А→действие→Б, факты реальные
- [ ] Оффер: цена, якорь, механика, кодовое слово, цель+дедлайн
- [ ] 10–20 хуков, каждый привязан к боли, без кликбейта-обмана
- [ ] 20–30 тем, разложены по углам, ни одной «мотивации вообще»
