# Фактчек: минимальный стандарт

## Три источника — не механическое правило

Количество ссылок не заменяет качество. Для официального решения достаточно подлинного документа; для спорного события нужны первоисточник, независимое подтверждение и позиция второй стороны. Для личной истории — запись Антона и запрет делать утверждения о чужих мотивах без доказательств.
| Тип утверждения | Доказательство | Особый контроль |
|---|---|---|
| Должность / статус | Официальный сайт или решение | Проверить в день публикации. |
| Закон / требование | Официальный текст + профильный юрист | Не пересказывать по старой памятке. |
| Цифра / сумма | Документ, методика, период | Указать, что именно посчитано. |
| Цитата | Полная запись, таймкод, контекст | Не склеивать фразы. |
| Фото / видео | Автор, дата, место, разрешение | Проверить монтаж и подпись. |
| Обвинение | Документы + позиция стороны + юрист | Без доказательств не публиковать. |
| Партнёрство | Письмо, договор, протокол | Интерес не равен соглашению. |
| Результат проекта | Акт, факт запуска, фото, пользователь | Не путать мероприятие с устойчивым продуктом. |
| Исторический факт | Архив / музей / профильный историк | Особенно для дат, лиц, техники, карт. |

## Формула безопасной честности

> КОГДА ДАННЫХ НЕ ХВАТАЕТ Не «мы всё выяснили», а: «На данный момент подтверждено… Не подтверждено… Мы направили запрос… Ответ ожидается до… Материал будет обновлён».

# Red Team: семь атак до публикации

1. Оппонент: «Это скрытая реклама собственного бизнеса». Где раскрыт интерес?

2. Юрист: «Фраза содержит утверждение о факте. Чем оно доказано?»

3. Избирательная комиссия: «Материал побуждает голосовать. Кто оплатил и где реквизиты?»

4. Житель: «После красивого ролика ничего не изменилось». Где статус и контроль?

5. Партнёр: «Вы присвоили общий результат». Все участники названы?

6. Федеральный редактор: «Почему эта локальная история важна всей России?»

7. Семья / герой: «Вы нарушили мои границы». Было ли информированное согласие на конкретный формат?

# Исправления и право на ответ

## Исправление

1. Зафиксировать исходную версию и время обнаружения ошибки.

2. Остановить дальнейшую дистрибуцию и автопостинг.

3. Оценить ущерб: факт, имя, сумма, безопасность, политика, реклама.

4. Исправить на всех площадках, а не только в исходном канале.

5. Добавить видимую пометку: что изменено, когда и почему.

6. Уведомить человека/организацию, если ошибка затрагивала их.

# Метрики: доверие → действие → результат → деньги
| Уровень | Что считать |
|---|---|
| Доверие | Возврат аудитории, сохранения, прямые сообщения, доля содержательных комментариев, исправления без потери аудитории. |
| Полезность | Переходы к инструкции, скачивания, обращения, ответы на опрос, завершённые действия. |
| Влияние | Официальные ответы, назначенные встречи, изменённый статус вопроса, новые партнёры. |
| Территориальный спрос | Запросы туроператоров, бронирования, группы, партнёры, упоминания, повторный интерес. |
| Контент | Удержание, досмотры, глубина чтения, доля органического распространения, возврат к серии. |
| Коммерция | Лиды, конверсия, выручка, валовая маржа, повторные клиенты, концентрация на одном заказчике. |
| Производство | Время от идеи до публикации, стоимость единицы, доля переработки, просрочки, ошибки. |
| Риск | Количество претензий, исправлений, материалов без источника, нарушений маркировки, инцидентов с правами. |

## Главные формулы

• Коэффициент результата = материалы с подтверждённым действием / все материалы «проблема → решение».

• Коэффициент переработки = число качественных производных / число мастер-материалов.

• Доля доверительного действия = сохранения + пересылки + обращения / охват.

• Коммерческая устойчивость = повторная выручка + диверсификация клиентов − зависимость от крупнейшего заказчика.

• Цена внимания = затраты производства / число целевых действий, а не просмотров.

> НЕ ФИКСИРОВАТЬ СЕЙЧАС Точные целевые охваты и подписчики не вшиваются в книгу: они быстро устаревают. В первый месяц снимается базовая линия, после чего цели утверждаются на квартал.
